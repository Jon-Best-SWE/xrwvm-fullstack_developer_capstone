# IBM Full Stack Software Developer Capstone

This project was completed as part of the IBM Full Stack Software Developer Professional Certificate program. The capstone demonstrates the development and integration of a cloud-native full-stack web application using modern front-end, back-end, database, API, containerization, and deployment technologies.

IBM provided the initial project template, application structure, and project requirements. I forked the supplied repository and implemented and integrated the required functionality to complete the capstone.
